# 🏫 중학교 교육용 3D 방탈출 웹 플랫폼 (3D Escape Room)

> 학생들이 QR 코드로 모바일/PC에 접속하여 3D 테마 방을 탐험하고, 교과 퀴즈를 풀어 재료를 수집한 뒤 가구를 제작하여 방을 탈출하는 인터랙티브 3D 교육 게임 플랫폼입니다.  
> 선생님을 위한 **문제 관리, 출제 문항 수 조절, 방 관리, 학생 기록, 실시간 총점 랭킹 관리자 패널**이 내장되어 있습니다.

---

## ✨ 주요 기능 요약

### 1. 🎮 학생 클라이언트 (Play Flow)
- **간편 접속**: 모바일/태블릿 QR 코드 스캔 또는 웹 링크 접속
- **학생 참가 등록**: 학년(1~3학년), 반, 번호, 이름 입력
- **3D 캐릭터 커스터마이징 스튜디오**:
  - **머리/헤어**: 댄디컷, 양갈래, 볼륨펌, 단발 보브컷, 투블럭, 캡 모자 + 6종 컬러 팔레트
  - **상의(옷)**: 교복 재킷(+타이/리본), 캐주얼 후드티, 니트 조끼+셔츠, 스포티 바람막이 + 8종 컬러
  - **하의(바지/스커트)**: 슬랙스 교복바지, 슬림 청바지, 플리츠 스커트, 조거팬츠 + 5종 컬러
  - **신발**: 에어 스니커즈, 클래식 로퍼, 하이탑 농구화 + 5종 컬러
  - **악세서리 & 피부**: 스마트 안경 토글, 학생 백팩, 피부톤 3종
  - **3D 턴테이블 드래그 회전 & 🎲 랜덤 스타일 생성 버튼**
- **Three.js 기반 3D 테마 룸 탐험**:
  - 1번 방: 도서관 / 2번 방: 과학실 / 3번 방: 박물관 / 4번 방: 공방
  - **PC 조작**: `W, A, S, D` (이동), `Shift` (달리기), `E` (조사하기), `C` (가구제작), `R` (랭킹)
  - **모바일/태블릿 조작**: 가상 조이스틱 터치 + [조사하기] / [제작하기] / [달리기] 플로팅 버튼
- **문제 풀이 & 재료 수집**: 방 안의 오브젝트 조사 -> 정답 시 점수와 **목재 🪵**, **금속 ⚙️** 획득
- **가구 제작 & 3D 방 배치**: 수집한 재료로 가구 제작 시 **3D 방에 실제로 가구가 소환·배치**됨
- **방 탈출 & 최종 랭킹**:
  - 필요 가구수 충족 시 비상 탈출구 게이트 언락
  - **※ 총점이 높은 순으로 순위 결정 (소요시간은 순위에 반영하지 않음)**

---

### 2. 🛡️ 선생님 관리자 패널 (Admin Panel)
- **보안 잠금**: 비밀번호 인증 방식 (기본 비밀번호: `1212`)
- **문제 관리 (Question Bank)**:
  - 교과 문제 추가, 수정, 삭제
  - **출제할 문제 개수(N개) 설정 & [적용하기]**: 총 등록된 문제 중 출제할 개수를 지정하고 [적용하기]를 누르면 즉시 게임에 반영 (순차 또는 랜덤 출제 모드 지원)
- **방 관리 (Room Config)**: 테마 방 정보 및 배치 현황 확인
- **학생 기록 관리**: 참여 학생 명단, 총점, 푼 문제 수, 제작 가구 현황 조회 및 전체 기록 초기화
- **랭킹 관리**: 실시간 명예의 전당 리더보드
- **시스템 설정 & QR코드**: 관리자 비밀번호 변경, 방탈출 필수 가구 수 조정, 학생 접속용 대형 QR 코드 생성

## 🚀 빠른 시작 (로컬 실행)

### 1. 패키지 설치
```bash
npm install
```

### 2. 서버 실행
```bash
npm start
```

### 3. 접속
- **내 컴퓨터 브라우저**: `http://localhost:3000`
- **같은 와이파이 내 모바일 기기**: 서버 구동 시 터미널에 표시되는 `http://[내IP]:3000` 접속
- **관리자 초기 비밀번호**: `1212`

## 🌐 서버 배포 가이드 (Deployment Guide)

다른 사람이나 학생들에게 실제 웹 링크로 서비스하기 위한 3가지 대표 배포 방법입니다.

### 방법 1. 클라우드 무료 배포 (Render.com) - ⭐ 가장 추천!
GitHub 레포지토리를 만들고 Render에 연결하면 **무료 HTTPS 주소**가 생성되어 누구나 접속할 수 있습니다.

1. **GitHub에 본 코드를 Push합니다.**
2. [Render.com](https://render.com)에 로그인 후 **[New +] -> [Web Service]**를 클릭합니다.
3. 내 GitHub 레포지토리를 선택하고 다음 항목을 입력합니다:
   - **Name**: 원하는 사이트 이름 (예: `middle-school-escape`)
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Plan**: `Free`
4. **[Deploy Web Service]**를 누르면 1~2분 뒤 `https://middle-school-escape.onrender.com` 같은 도메인이 발급되며 즉시 전 세계 어디서나 접속할 수 있습니다!

---

### 방법 2. 클라우드 VPS 서버 배포 (AWS, Oracle Cloud, Naver Cloud 등)
독립적인 리눅스(Ubuntu) 서버에 직접 배포하는 방식입니다.

1. **서버에 Node.js 설치**:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs git
   ```
2. **코드 클론 및 실행**:
   ```bash
   git clone <내_깃허브_주소>.git
   cd <레포지토리_폴더>
   npm install
   ```
3. **무중단 프로세스 매니저(PM2) 실행**:
   ```bash
   sudo npm install -g pm2
   pm2 start server.js --name "escape-game"
   pm2 startup
   pm2 save
   ```
4. **포트 개방**: 서버 방화벽(Security Group)에서 `3000`번 포트(또는 80/443 포트)를 개방합니다.

---

### 방법 3. 학교/학원 내부 Wi-Fi로만 배포 (외부 서버 비용 0원)
1. 교내 컴퓨터에서 `npm start`로 서버를 실행합니다.
2. 터미널에 출력되는 `http://192.168.x.x:3000` 주소를 확인합니다.
3. 메인 화면의 **[학생 접속용 QR코드]**를 빔프로젝터에 띄우면, 같은 학교 Wi-Fi에 연결된 학생들의 스마트폰/태블릿으로 즉시 접속하여 수업을 진행할 수 있습니다.
